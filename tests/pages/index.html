Browser Video Player — test pages

Serve this folder over HTTP (content scripts don't run on file:// unless enabled):

python3 -m http.server 8000 --directory tests/pages
  1. basic.html — single paused video
  2. multi.html — 3 videos incl. tiny playing preview
  3. dynamic.html — video appears after 10 s
  4. unsupported.html — broken + MSE sources

Requires internet: fixtures use Google's public sample videos.
